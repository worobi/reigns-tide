## Main Direction

Create a tender, faith-centered remembrance slideshow that feels like a love letter from Mommy to Reign. The emotional path should move from love and missing her, into pride, comfort in faith, the community she inspired, and a final bright celebration of her superhero spirit.

The first version should be built vertically at `9:16` for phones, Facebook/Reels, and family sharing. A second `16:9` ceremony-screen version can use the same order with softened background fills behind portrait photos.

## Visual Style

- Colors: soft ocean blue, warm gold, white, and gentle pink accents.
- Motifs: light, sparkle, tide/water movement, prayer, stars, Spider-Man touches used sparingly.
- Text style: simple white or warm gold text, no heavy effects, no crowded paragraphs.
- Motion: slow zooms on photos, gentle fades, no flashy transitions.
- Tone: beautiful, clear, child-honoring, faith-filled, not overly produced.

## Text Overlay Rules

- Keep each text card to `1-2` short lines.
- Never put the full message on one slide.
- Use Mommy's full message as voiceover if possible.
- If there is no voiceover, use the shorter text beats above.
- Keep text away from faces.
- Let the last line hold long enough to read without rushing.

## Media Selection

Use about `45-60` total moments for a 3:27 video:

Suggested video clip length:

Suggested photo timing:
